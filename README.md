#Mis see on

See on õppeprojekt, kus loodi puhta JavaScripti frontend e-poele ning Node.js + Express backend, mis võtab andmeid VOCO õppeserveri MariaDB-st ja serveerib neid APIdega frontendile.

#Mis Node.js versioonil see põhineb

Kasutatud on Node v22.10.6

#Kuidas seda käivitada

Esiteks klooni see repo, siis käivita 'npm install' kloonitu kaustas ning lõpuks kasuta 'npm run dev' arenduskeskonna käivitamiseks või 'npm start' produksiooni keskonna käivitamiseks. Käivitatud server peaks serveerima lehe vaikimisi port 3000-del, e.g. localhost:3000.
